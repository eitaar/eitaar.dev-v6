# eitaar.dev

eitaar's personal portfolio site: an artistic, 3D-led showcase of things eitaar has built and written, aimed mainly at fellow developers.

## Language

### Content

**Project**:
A thing eitaar has built, presented as an object with a one-line summary, category and tech stack.
_Avoid_: Work, product, app

**Featured Project**:
A Project singled out for the homepage and given a full writeup (what it is, why it exists, how it works).
_Avoid_: Top project, highlight, pinned project

**Writeup**:
The long-form body of a Featured Project's detail page; describes the Project itself, not a technique.
_Avoid_: Case study, article

**Post**:
A standalone technical article about a topic (a technique, a problem hit, how something was solved); may reference related Projects but is not about one Project as a whole.
_Avoid_: Blog, article, note

**Skill**:
A tool, language or medium eitaar uses or is learning, listed compactly on the homepage.
_Avoid_: Tech, stack item

### Scene

**Poolrooms**:
The flooded, fully tiled, vaulted passages the homepage background moves through, lit by daylight from above.
_Avoid_: Pool, backrooms, 3D background

**Depths**:
The far part of Poolrooms where the light fails; the page ends there, growing as dark as it can, with the far doorway always out of reach.
_Avoid_: Alley, end, exit, dark mode

**Anchor**:
A fixed point on the camera's path that lines up with a homepage section (entrance, pool, depths).
_Avoid_: Waypoint, keyframe, stop
